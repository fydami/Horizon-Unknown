## ✦ Что внутри

| Раздел | Что это |
|---|---|
| **Главная** | Стартовая страница, которую можно собирать из блоков: заголовок, текст, картинка, цитата, цифра, кнопка. |
| **Граф** | Все карточки на одной карте. Связи цветные по типу (союзник, враг, семья, наниматель, тайная связь, непроверенная). Есть фильтры, миникарта, масштаб и автораскладка. |
| **Персонажи** | Досье с портретом, цитатой, описанием и связями. |
| **Организации** | То же, плюс **структура**: иерархия, ЧВК, крайм-семья или сеть ячеек. |
| **Истории** | Тома и сюжеты с привязкой к героям и организациям. |
| **Таймлайн** | Хронология событий с участниками и местами. |

### Мелочи, которые стоит заметить

- **Режим фокуса на графе.** Наведите курсор на карточку, и связанные с ней подсветятся, а остальное притихнет.
- **Окно связей.** В досье показана мини-карта окружения карточки и список связей с фильтром по типу.
- **Скрытый текст.** Фрагменты, помеченные как секретные, закрашены чёрным. Нажмите на такой фрагмент, чтобы раскрыть его.
- **Штампы.** `CONFIDENTIAL`, `KIA`, `WANTED` и другие можно ставить прямо на карточки.
- **Живой фон.** Топографическая карта, радар и «разведывательные» надписи, которые меняются в зависимости от того, что есть в базе.
- **Светлая и тёмная темы.** Выбираются автоматически по настройкам системы, переключаются кнопкой.

## 🗂 Структура репозитория

```
Horizon-Unknown/
├── index.html    # весь сайт: разметка, стили и скрипт в одном файле
└── data.json     # все данные: карточки, связи, главная, таймлайн
```

Сайт полностью статический. Сборки и серверной части нет, пакетов устанавливать не нужно.

---

## ✏️ Как обновлять контент

Данные редактирует владелец прямо в браузере. Изменения сохраняются в `localStorage` и **не** отображаются у посетителей, пока их не опубликуют:

1. Откройте сайт в режиме редактирования и внесите правки.
2. Нажмите **«Данные»** и скопируйте JSON из поля.
3. Вставьте его в `data.json` в репозитории и сделайте коммит.
4. Через минуту GitHub Pages покажет обновлённую версию всем.

> Положение карточек на графе, связи, текст досье, главная страница и таймлайн хранятся в одном `data.json`.

## 🚀 Запуск локально

```bash
git clone https://github.com/weisez/Horizon-Unknown.git
cd Horizon-Unknown
python3 -m http.server 8000
```

Откройте <http://localhost:8000/?view> в браузере. Локальный сервер нужен для того, чтобы страница могла загрузить `data.json`.
